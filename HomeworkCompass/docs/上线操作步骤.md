# HomeworkCompass 上线操作步骤

> 面向两种交付形态：**A. 命令行工具（`hw`）** 和 **B. HTTP 服务（被 app 前端调用）**。
> 两者共用同一套核心库和同一张底图资源。

---

## 0. 上线前必须知道的三件事

| 事项 | 现状 | 影响 |
|------|------|------|
| **出图是占位底图** | 仓库自带 `assets/base_robot_quest-map.png`（可爱机器人主题，2480×3508@300dpi），**必须显式传 `--base`** 才用得上 | 不传 `--base` 出的图只有框和字，没有装饰，不是可打印成品 |
| **解析默认联网花钱** | `hw parse` **不写** `--offline` 会调 `qwen-plus`；`--offline` 才是离线兜底 | 线上批量跑记得加 `--offline`，或明确接受调用成本 |
| **pending 非空拒绝出图** | 这是产品契约（宁缺毋编），不是 bug | 脚本要处理退出码 2/3，不能当失败重试 |

## 1. 环境准备

### 1.1 运行期依赖

```bash
python3 --version        # 必须 ≥ 3.13
```

### 1.2 安装（开发机）

```bash
cd HomeworkCompass
python3 -m pip install -e ".[dev]"     # 开发/自测：带 pytest
```

### 1.3 安装（生产机）

```bash
cd HomeworkCompass
python3 -m pip install .               # 只装运行期依赖（Pillow）
```

> 若要起 HTTP 服务（形态 B），额外装两个包：
> ```bash
> python3 -m pip install "fastapi>=0.115" "uvicorn[standard]>=0.30"
> ```
> **注意**：`fastapi`/`uvicorn` 目前**没有写进 `pyproject.toml`**（那里只有 `Pillow`），
> 生产部署必须显式安装，或先把它们补进 `pyproject.toml` 的可选依赖再重新打包。

### 1.4 字体（决定中文能不能画出来）

渲染器按顺序探测这些路径，取第一个存在且**中文字形覆盖完整**的：

```
/System/Library/Fonts/PingFang.ttc
/System/Library/Fonts/Hiragino Sans GB.ttc
/System/Library/Fonts/STHeiti Medium.ttc
/Library/Fonts/Arial Unicode.ttf
/System/Library/Fonts/Supplemental/Songti.ttc
/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc
/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc
```

- **Linux 服务器**：装 `fonts-noto-cjk`（或 `fonts-wqy-zenhei`）：
  ```bash
  apt-get install -y fonts-noto-cjk
  ```
- **随包字体（推荐，不依赖服务器）**：把任意中文 `.ttc/.ttf` 放进 `fonts/` 目录，
  `tools/run-api.sh` 会自动设置 `HW_FONT` 指向它，打包时也会一起进 tar 包。
  详见 `fonts/README.md`。也可手动 `HW_FONT=/abs/path/xxx.ttc bash tools/run-api.sh`。
- **自检**（缺字会静默画成豆腐块，必须验）：
  ```bash
  python3 -c "
  from homework_compass.layout.fonts import load_font
  print('字体 OK:', load_font(40))
  "
  ```
  报 `FontError`（退出码 5）就是字体没有中文，把中文 ttc 路径写进 `config.toml` 的 `fonts = [...]`。
  （若没 `pip install`，在仓库根目录跑时前面加 `PYTHONPATH=src`。）
- 用 `hw render` 出图后**人眼扫一遍**每个字，别只看程序没报错。

## 2. 形态 A：命令行工具上线

### 2.1 准备配置

在**运行目录**放 `config.toml`（机器相关）与 `profile.toml`（长期偏好），不认识的键会直接报错：

```toml
# config.toml
out_dir = "/var/lib/homework-compass/out"
fonts = ["/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc"]
```

```toml
# profile.toml
name = "小宇"
default_skeleton = "quest-map"
default_skin = "space"
```

优先级：**命令行 > 环境变量 > config.toml > profile.toml > 内置默认**。

### 2.2 配置凭证（仅在需要联网解析/OCR 时）

```bash
export DASHSCOPE_API_KEY=sk-xxxx
```

凭证**只能**来自环境变量（或当前目录 `.env`），写进 toml 会直接被拒。
`.env` 已在 `.gitignore` 里。

### 2.3 跑一遍最小闭环

```bash
cd HomeworkCompass
hw parse --file tests/fixtures/raw1.txt --name 小宇 --offline \
         --date 2026-11-06 --out /tmp/hw.json
hw render /tmp/hw.json \
         --base assets/base_robot_quest-map.png \
         --out /tmp/hw_out/
```

期望输出：

```
写入：/tmp/hw.json｜可出图 5 项｜待确认 0 项
成品：/tmp/hw_out/homework_2026-11-06_quest-map_dinosaur.png  (2480x3508 @300dpi)
```

**自检清单**
- [ ] 图片尺寸 2480×3508，DPI 300
- [ ] 每个字都清晰，没有豆腐块
- [ ] 「别忘了」区和「通关奖励」区在纸上有位置
- [ ] 打印出来看一眼（A4、实际大小、不缩放）

### 2.4 上线脚本的正确分支写法

```bash
hw parse --file raw.txt --out hw.json
case $? in
  0) hw render hw.json --base assets/base_robot_quest-map.png --out out/ ;;
  3) hw confirm hw.json            # 有人处理 pending
     [ $? -eq 0 ] && hw render hw.json --base assets/base_robot_quest-map.png --out out/ ;;
  2) echo "还有 pending，拒绝出图" >&2; exit 2 ;;
  4) echo "参数/数据错了，别重试" >&2; exit 4 ;;
  5) echo "接口或字体坏了，别重试" >&2; exit 5 ;;
esac
```

退出码含义：

| 码 | 含义 | 该做什么 |
|----|------|----------|
| 0 | 成功 | — |
| 2 | 有 pending，拒绝出图 | 人工确认，**不要重试** |
| 3 | 解析/确认后仍有 pending | `hw confirm` 处理 |
| 4 | 参数错误 / 字段白名单 / `LayoutError`（>6 项）/ 字体错误 | 修数据，**不要重试** |
| 5 | API 错误 / 模型返回垃圾 / 字体错误 | 查 key、余额、字体，**不要重试同一请求** |

## 3. 形态 B：HTTP 服务上线（app 前端调用）

### 3.1 架构位置

```
app/frontend  ──HTTPS──►  Compass 服务（本服务，独立域名）
                             │
                             └─► DashScope（OCR / 文本解析）
```

- 服务与 `backend/`（Go Kratos，8000）**并行独立**，不经过它。
- 前端基址由 `app/frontend/.env` 的 `VITE_COMPASS_API` 决定。

### 3.2 启动

```bash
cd HomeworkCompass
bash tools/run-api.sh 8100
```

脚本做了三件事：绑定 `0.0.0.0`（不是 `127.0.0.1`，否则前端用 `localhost` 会解析到 `::1` 连不上）、从当前目录 `.env` 读 `DASHSCOPE_API_KEY`、以 `PYTHONPATH=src` 启动。

生产环境用进程管理器托管，例如 systemd：

```ini
[Unit]
Description=HomeworkCompass API
After=network.target

[Service]
Type=simple
User=homework
WorkingDirectory=/opt/HomeworkCompass
Environment=PYTHONPATH=src
Environment=DASHSCOPE_API_KEY=sk-xxxx      # 生产建议用 EnvironmentFile
ExecStart=/opt/HomeworkCompass/venv/bin/python -m uvicorn homework_compass.api:app --host 0.0.0.0 --port 8100 --workers 2
Restart=always

[Install]
WantedBy=multi-user.target
```

> 用 `--workers 2` 时要注意：渲染是 CPU 密集（Pillow 画 2480×3508），多 worker 会更吃内存。
> 低并发场景 `--workers 1` 足够；渲染慢时优先加内存，别先加 worker。

### 3.3 反向代理

```nginx
server {
    listen 443 ssl http2;
    server_name compass.gameyeah.net;         # 换成你的独立域名

    client_max_body_size 12m;                 # 作业照片上传

    location / {
        proxy_pass http://127.0.0.1:8100;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 180s;              # OCR 慢，给足超时
        proxy_send_timeout 180s;
    }
}
```

**HTTPS 是硬要求**：小程序正式版只认 `https`，`localhost` 不能进「request 合法域名」。

### 3.4 接口清单

| 方法 | 路径 | 作用 | 备注 |
|------|------|------|------|
| GET | `/api/health` | 健康检查 | `{"code":0,"data":{"ok":true}}` |
| GET | `/api/options` | 可用骨架与皮肤 | 目前 1 骨架 5 皮肤 |
| POST | `/api/parse` | 文本 → 结构化作业 | body `{text,name,date}` |
| POST | `/api/parse/image` | 图片 → OCR → 结构化作业 | multipart，字段名 `file`；query 带 `name`/`date` |
| POST | `/api/correct` | 改某项字段 | `{hw,seq,field,value}`；字段白名单 `subject/task/quantity/requirements/priority/type` |
| POST | `/api/drop` | 删掉整项 | `{hw,seq}`；删后其余项重新编号 |
| POST | `/api/dismiss` | 忽略一条待确认 | `{hw,pending_id}` |
| POST | `/api/patch` | 改标题口号/姓名 | `{hw,slogan}` |
| POST | `/api/render` | 出图 | `{hw,skeleton,skin}`；**pending 非空返回 409** |
| GET | `/api/image/{name}` | 取图 | 返回 PNG |

统一响应体：`{"code":0,"data":{...}}`；出错时 `code≠0` 或 HTTP 4xx/5xx + `detail` 文字。

### 3.5 前端配置

`app/frontend/.env`：

```bash
# 开发
VITE_COMPASS_API=http://localhost:8100

# 生产（换注释掉上面那行）
VITE_COMPASS_API=https://compass.gameyeah.net
```

改完要**重新构建前端**（HBuilderX → 发行），`.env` 是构建期注入。

### 3.6 微信小程序上线必做

1. **微信公众平台** → 小程序 → 开发管理 → 开发设置 → **服务器域名** → **request 合法域名**
   加入 `https://compass.gameyeah.net`（不带路径、不带末尾斜杠）。
2. **downloadFile 合法域名**：也要加（取图走的是 `<image src>`，小程序同样受域名限制）。
3. 开发者工具里的「不校验合法域名」**只在开发期有效**，预览和正式版一律校验。

### 3.7 CORS

服务默认 `allow_origins=["*"]`，前端直连不会被 CORS 拦。
若要收紧，改 `src/homework_compass/api.py` 的 `add_middleware` 参数为具体域名。

### 3.8 接口冒烟

```bash
BASE=http://127.0.0.1:8100
curl -s $BASE/api/health

# 解析
curl -s -X POST $BASE/api/parse -H 'Content-Type: application/json' \
  -d '{"text":"1.数学：完成练习册第12-13页","name":"小宇","date":"2026-11-08"}'

# 出图（用上一步返回的 data 当 hw）
curl -s -X POST $BASE/api/render -H 'Content-Type: application/json' \
  -d '{"hw":<上一步的 data>,"skeleton":"quest-map","skin":"dinosaur"}'
```

### 3.9 出图用的是占位底图 —— 要真底图

HTTP 层目前**没有** `--base` 入口，`render()` 传的是 `base=None`，所以走占位底图。
两种选择：

- **A（推荐，马上能用）**：在 `api.py` 的 `do_render` 里加一个 `base` 参数，指向
  `assets/base_robot_quest-map.png` 的绝对路径，渲染前用 `Path` 校验它在 A4 尺寸。
- **B（长期）**：把风格底图做成独立资源目录，按 `skin` 取对应底图；底图仍必须满足
  「九个区域内部纯白、无字无图、尺寸精确 2480×3508」。

底图的坐标契约用 `hw zones` 打印，用 `hw prompt --skeleton quest-map --skin <skin>`
生成生图提示词（只打印，不花钱）。

## 5. 常见故障

| 现象 | 原因 | 处理 |
|------|------|------|
| 前端报「跨域/连接失败」 | 服务只绑了 `127.0.0.1` | 用 `tools/run-api.sh`（绑 `0.0.0.0`） |
| 「未设置环境变量 DASHSCOPE_API_KEY」 | 变量名拼错或没注入 | 必须是 `DASHSCOPE_API_KEY`（中间是 **I**，不是 L）；`run-api.sh` 会读当前目录 `.env` |
| 图里中文是方块 | 字体不含 CJK | 装 `fonts-noto-cjk`，或 `config.toml` 里指定 `fonts` |
| 退出码 2 | 有 pending | 人工确认，**不是故障** |
| 退出码 4「作业项超过 6 条」 | 单日作业太多 | 拆两页（分页尚未实现） |
| 退出码 5 | key 失效/额度用尽/字体错 | 查 key、余额、字体 |
| 小程序真机 `url not in domain list` | 合法域名没配 | 微信公众平台加域名 |

## 7. 打包发布

在源码目录产出自包含的部署包（含源码、10 张主题底图、启动脚本、文档）：

```bash
cd HomeworkCompass
bash tools/build.sh              # 先跑测试，再校验底图，最后打包
bash tools/build.sh --skip-test  # 跳过测试（不推荐）
```

产物在 `dist/`：

```
homework-compass-<version>-<git短hash>.tar.gz
homework-compass-<版本>.tar.gz.sha256        # 校验和
```

**打包时自动检查**：

- 单元测试必须全绿（否则拒绝打包）
- 主题底图必须 ≥10 张且尺寸均为 2480×3508（缺图会让线上静默回落占位图）
- 自动排除 `__pycache__` / `*.pyc` / `*.egg-info` / 演示数据

**目标机部署**：

```bash
tar -xzf homework-compass-0.1.0-<hash>.tar.gz
cd homework-compass-0.1.0-<hash>

python3 -m pip install '.[api]'    # HTTP 服务；只用 CLI 装 '.'
bash tools/run-api.sh 8100          # HW_BASE_DIR 自动指向 assets/bases
```

> 若底图放在别处，用 `HW_BASE_DIR=/your/path/assets/bases bash tools/run-api.sh` 覆盖。
