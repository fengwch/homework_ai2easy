# 主题底图：生成、映射与复用

> **目标图的装饰层从哪来、怎么改、怎么加新主题。**
>
> 三者分工固定：**底图只画装饰**（编程绘制，无文字）→ **文字层由渲染器精确落在留白框** →
> 合成 A4 成品。这是「双层合成」的核心，也是「改文字不用重新生图」的前提。

- **专属**：每个主题单独画的装饰图形，视觉区分明显。
- **通用**：同一套几何装饰 + 不同配色，视觉差异小，后续可按需升级为专属。

### 打印墨量约束

所有主题都要**低墨量**：深色只作细描边（线宽 3–5px），不做大面积深色填充。
自检方法（见 §4）统计深色像素占比，正常在 **2% 左右**；超过 10% 说明某处铺了大块深色。

## 2. 元信息在哪：`layout/themes.py`

**唯一事实来源。** 前端、渲染、生成脚本、文档都读它，改主题只改这一处。

```python
from homework_compass.layout.themes import get_themes, get_theme, theme_for_interests

get_themes()                 # → [Theme(key, cn, accent, deco, deco_dark, bg, interest_tags, base_file), ...]
get_theme("dinosaur")        # → Theme 或 None
theme_for_interests(["恐龙", "汽车"])  # → ['dinosaur', 'car', 'space', ...] 兴趣匹配的排前面
```

每个 `Theme` 的字段：

| 字段 | 用途 |
|------|------|
| `key` | 主题标识，同时是 `skin` 参数值 |
| `cn` | 中文名，前端展示 |
| `accent` | 框描边 / 星标色 |
| `deco` | 装饰主色（浅） |
| `deco_dark` | 装饰描边色（深，只用于线条） |
| `bg` | 页面底色（浅） |
| `interest_tags` | 对应的孩子兴趣标签 |
| `base_file` | 底图文件名 `<key>_quest-map.png` |

## 3. 生成 / 更新底图

### 全量重新生成

```bash
cd HomeworkCompass
PYTHONPATH=src python3 tools/gen_bases.py
```

输出到 `assets/bases/<key>_quest-map.png`（2480×3508 @300dpi），并逐框自检留白纯白。

### 只改某一个主题

1. 改 `src/homework_compass/layout/themes.py` 里对应主题的配色，或
2. 改 `tools/gen_bases.py` 里对应的 `_draw_<主题>` 画笔函数，或
3. 在 `_DRAW` 字典里把某主题从 `_draw_generic` 换成自己的画笔。

然后重跑上面的命令（会重新生成全部 10 张，幂等）。

### 新增一个主题

```python
# 1) themes.py 的 _THEME_PALETTES 加一行
"train": {"accent": "#B5651D", "deco": "#E0A96D", "deco_dark": "#7A4312", "bg": "#FBF4EC"},
# 2) _CN 加中文名
"train": "小火车",
# 3) _THEME_ORDER 加到列表末尾（决定默认展示顺序）
# 4) 若想让它对应某个兴趣，_INTEREST_TO_THEME 加映射
"托马斯": "train",
```

```python
# 5) gen_bases.py 写一个画笔（可选，不写就用通用几何）
def _draw_train(d, t, z, stations, motif=None):
    ...

# 6) 注册到 _DRAW
"train": _draw_train,
```

重跑生成脚本即可。

## 4. 自检：留白必须是白的

渲染器会把文字画在 9 个留白框里。底图如果装饰压到框内，文字就会压在图案上。

生成脚本自动检查：每个框**内缩 14px** 取样，非白像素必须 ≤2 个（圆角抗锯齿），超过就是装饰压框。

```
dinosaur   dinosaur_quest-map.png   留白纯白=True
space      space_quest-map.png      留白纯白=True
```

手动复核单张：

```python
PYTHONPATH=src python3 -c "
from PIL import Image
from homework_compass.layout.skeleton import get_skeleton
img = Image.open('assets/bases/space_quest-map.png').convert('L')
Z = {z.key: z.rect for z in get_skeleton('quest-map').zones}
for name, (x0, y0, x1, y1) in Z.items():
    crop = img.crop((x0+14, y0+14, x1-14, y1-14))
    print(name, sum(1 for v in crop.getdata() if v < 250))
"
```

坐标契约用 `hw zones` 查看。

## 5. 映射：出图时怎么选到底图

### 优先级

1. 显式传 `base=<路径>` → 用这张（覆盖一切）
2. 否则按 `skin` 去 `base_dir` 找 `<skin>_quest-map.png` → 存在就用
3. 否则 → 占位图（`used_placeholder=True`）

### CLI

```bash
hw render hw.json --skin space --out out/
```

### 库

```python
from homework_compass.pipeline import render
r = render(hw, skin="space", base_dir=Path("assets/bases"), out_dir=Path("out"))
r.used_placeholder   # False 表示用了真底图
```

### HTTP（供 app 前端调用）

- `GET /api/options` → 返回全部主题（`themes`）与骨架
- `GET /api/themes/suggest?interests=恐龙,太空` → **按孩子兴趣排好序**的主题列表
- `POST /api/render` `{hw, skeleton, skin}` → 自动用对应底图

前端候选屏在进入时调 `/api/themes/suggest`，把匹配孩子兴趣的主题排到最前，并提示「已按兴趣为你推荐」。

## 6. 关键不变量（改底图前必读）

1. **底图不含任何文字。** 所有中文由 `compose.py` 绘制；底图里写字会与文字层重叠。
2. **留白框内部必须纯白**，位置由 `skeleton.py` 的坐标契约决定，不能自行挪动。
   **奖励框（reward）不画进底图**——家长不填奖励时该区域保持干净，由渲染层按需绘制。
3. **尺寸固定 2480×3508 @300dpi**；页边距 ≥10mm。
4. **低墨量**：深色只做细描边，不做大面积填充（打印机省墨、黑白可读）。

改底图后至少跑一次 `tools/gen_bases.py`（自带自检），再 `hw render` 出一张人工看一眼。
