# 每日作业目标生成器 — 方案设计文档

---

## G — Goal（产品目标）

把老师每天发布的、格式各异的作业内容，一键转化为一张**孩子看得懂、愿意执行、可打印张贴的 A4「每日作业目标图」**。

核心价值主张：

1. **说明白**：作业的每一项（科目、内容、数量、要求）在图上一目了然，孩子无需家长口头转述。
2. **突出要点**：重点任务、易漏项（如"签字""背诵打卡""带材料"）被视觉强调。
3. **有动力**：用流水线、闯关游戏等趣味样式，把"任务清单"变成"目标地图"，降低孩子的抵触感。
4. **零设计门槛**：家长只需复制粘贴，样式由生成器和 AI 画图工具完成。

成功标准（V1 验收口径）：

- 从粘贴作业到拿到可打印成品图 ≤ 5 分钟；
- 作业项解析准确率：结构完整项 100% 呈现、无遗漏无杜撰，模糊项 100% 提示家长确认；
- 打印后 A4 纸面上正文文字清晰可读（正文 ≥ 14pt 等效字号）。

## R — Role（用户角色）

| 角色 | 描述 | 与产品的关系 |
|------|------|--------------|
| 家长（主操作者） | 每天接收老师作业通知，负责粘贴上传、选择样式、确认编辑、下载打印 | 全流程操作者 |
| 学生（最终使用者） | 小学阶段为主（建议 1–6 年级），看图执行作业、勾选/闯关打卡 | 图片的阅读者与互动者 |
| 老师（内容源头，非用户） | 在微信群/钉钉/纸质通知等渠道发布作业 | 只产出原始内容，不使用本产品 |

典型场景：晚上 7 点，家长把班级群里老师发的作业消息整段复制，粘贴进生成器；30 秒后看到 3 种风格的目标图预览；选了"闯关游戏"风格，把第 3 项的"背诵课文"改成孩子昵称里的说法；下载 A4 图片，打印贴在书桌前。孩子每完成一项就去图上盖一个章/画一个勾。

## I — Input（输入设计）

### I-1 作业内容的来源格式（必须全部兼容）

| 格式 | 示例 | 处理策略 |
|------|------|----------|
| 纯文本消息 | "今日作业：1.数学练习册P12-13；2.语文抄写生字2遍；3.英语听读打卡" | 直接解析 |
| 带 emoji / 符号的群消息 | "📚语文：背诵《静夜思》✅家长签字" | 清洗装饰符号后解析 |
| 截图/照片 | 老师板书拍照、纸质作业单拍照 | OCR（多模态识图）转文本，进入同一解析管线，识别结果先给家长确认 |
| 语音转文字 | 家长用手机语音输入转出的文字 | 视为低质量文本，解析后强制家长确认 |
| 混合多项 | 多个科目 + 每项多个子任务 + 附加要求（签字/带材料/打卡） | 层级化解析（见 I-2） |

### I-2 解析后的结构化数据模型

解析器把任意输入统一转成如下结构（这是全流程的中枢数据）：

```json
{
  "date": "2026-11-02",
  "student_name": "（可选，家长设置一次后默认填入）",
  "items": [
    {
      "seq": 1,
      "subject": "数学",
      "task": "完成练习册 P12–P13",
      "quantity": "2页",
      "requirements": ["用铅笔", "家长检查后签字"],
      "priority": "high",        // high / normal，由"明天交""重点"等关键词或家长手动设定
      "estimated_minutes": 20,   // 可选，AI 估算 + 家长可改
      "type": "written"          // written / oral / reading / checkin / material
    }
  ],
  "extras": ["带美术材料：彩泥"],   // 非作业类但易漏的事项，单独醒目呈现
  "unresolved": []                 // 解析不了、有歧义的原文片段，必须列出让家长确认
}
```

关键规则：

- **宁缺毋编**：AI 解析不确定的内容一律进 `unresolved`，请家长补充，绝不猜测补全。
- **要点提取**：自动识别"签字、背诵、打卡、明天带、测验"等高优关键词并标 `priority: high`。
- **一次设置、长期复用**：学生姓名、昵称、喜欢的主题风格（恐龙/太空/公主…）存入偏好，之后每天一键生成。

## P — Process（核心流程，对应您提出的 6 步）

```
老师发作业            家长操作                 生成器                      AI 画图
（各种格式）──► ①复制/拍照上传 ──► ②解析+结构化 ──► ③生成目标图 ──► ④家长选择/再编辑 ──► ⑤下载 ──► ⑥打印
                                    │                  │
                                    └─ 歧义项回问家长   └─ 输出 2~3 种风格候选（A4）
```

### ① 作业接入
- 文本粘贴框（主入口）＋ 图片上传（OCR）＋ 历史模板（"和昨天一样，只改第 2 项"）。

### ② 解析与确认
- 展示结构化解析结果（清单形式），家长可增删改每一项；
- `unresolved` 项高亮提示，必须处理完才能进入下一步。

### ③ 生成多风格 A4 目标图（产品亮点）
- 默认一次生成 **2–3 种不同风格**候选（家长也可指定单一风格重生成）；
- 每张图必须做到：**每一项作业说明白**（科目+内容+数量+要求）、**要点突出**（高优项用徽章/星标/放大色块）、**留有互动区**（勾选框/闯关印章位/进度条）。

### ④ 选择与再编辑
- 预览对比 → 选定一张 → 轻量编辑：改文字、换配色、调项目顺序、换标题（如"小宇的闯关地图"）；
- 不满意可"换一批风格"重新生成。

### ⑤ 下载
- 输出 **A4 打印级图片**（PNG，300dpi）；可选附带 PDF 版本便于直接打印。

### ⑥ 打印
- 图片按 A4 竖版设计，页边距 ≥ 10mm，黑白打印机下仍可读（见"图片规格"）。

## 风格模板库（亮点设计）

模板库 = 「版式骨架 × 主题皮肤」两层组合：骨架决定信息布局与互动方式，皮肤决定视觉风格（恐龙、太空、海洋、像素、手绘卡通…）。骨架固定保证"每项作业都说得明白"，皮肤自由保证"每天不重样"。

### V1 首批 6 种版式骨架

| # | 骨架 | 版式描述 | 互动方式 | 适合 |
|---|------|----------|----------|------|
| 1 | **流水线工厂** | 作业项排成传送带，每项是一个"工位"，从"原料区"流向"成品区" | 完成一站盖一个合格章 | 任务多、想强调顺序感 |
| 2 | **闯关游戏地图** | S 形关卡路径，每项作业是一个关卡（BOSS 关=最重要任务），终点是宝箱奖励 | 过一关涂亮一格，终点兑换约定的小奖励 | 需要激励、爱玩游戏的孩子 |
| 3 | **登山/爬梯进度** | 纵向山峰或阶梯，作业项自下而上分布，顶部是旗帜 | 完成一项向上爬一格 | 任务量适中、强调"越努力越接近目标" |
| 4 | **寻宝清单（Checklist）** | 卷轴/藏宝图样式清单，每项带勾选框，重点项画红叉标记"宝藏" | 打勾 | 高年级、偏简洁实用 |
| 5 | **列车车厢** | 小火车头+每节车厢装一项作业，车头写日期与姓名 | 完成一节"车厢亮灯" | 低年级、任务 3–6 项 |
| 6 | **果园采摘** | 果树上的果实=作业项，篮子区留白写"今日收获" | 完成一项涂红一个果子 | 低年级、温和鼓励型 |

### 版式通用规范（所有骨架强制遵守）

- 顶部：日期 + 学生姓名 + 一句当日目标口号（可自定义）；
- 主体：每个作业项必含「科目图标 + 任务内容 + 数量/页码 + 特殊要求」四要素；
- 高优项：星标/红色徽章"重要"；
- 易漏事项（带材料/签字）：底部独立的"别忘了"警示条；
- 互动区：每项旁的勾选框/印章位；
- 底部：完成后的奖励/评语留白区（家长手写）。

### 主题皮肤库（V1 首批 8 款）

恐龙、太空宇航、海底世界、像素游戏、手绘涂鸦、糖果甜品、交通工具、森林动物。每款皮肤定义主色板（含"黑白打印友好"变体）、图标风格、边框装饰。皮肤可持续扩充，也可根据孩子喜好定制。

## 图片规格

| 项目 | 规格 |
|------|------|
| 尺寸 | A4 竖版 210×297mm；像素 2480×3508（300dpi） |
| 页边距 | 四周 ≥ 10mm，防止打印机裁切 |
| 字号 | 标题 ≥ 28pt 等效，作业项正文 ≥ 14pt 等效，附加说明 ≥ 10pt |
| 色彩 | 彩色版 + 黑白友好版（关键信息不依赖颜色区分，用形状/图标/粗细辅助） |
| 格式 | PNG（下载打印）；可选 PDF（A4 定尺，直接打印不缩放） |
| 文字渲染 | **所有作业文字必须由排版引擎绘制，禁止依赖 AI 生图模型直接写中文**（详见技术选型） |

## 交互设计

### 主流程界面（网页版形态下的 5 屏）

1. **输入屏**：大粘贴框 + 「上传图片（OCR）」+ 「用昨天的」三个入口；右上角显示孩子偏好（姓名/常选风格）。
2. **确认屏**：解析结果清单（卡片式，可编辑每项的科目/内容/要求/优先级），歧义项红色高亮置顶，底部「确认无误，生成目标图」。
3. **候选屏**：2–3 张风格缩略图横向对比，点击放大预览；「换一批」「指定风格重新生成」。
4. **编辑屏**：选定图的所见即所得轻编辑——点文字改文字、切换配色、拖动排序、修改标题口号。
5. **下载屏**：PNG / PDF 按钮 + 打印小贴士（"打印时选择 A4、实际大小、不缩放"）。

### 对话式形态（阶段 1 MVP，零开发）

同一流程在 AI 助手对话内完成：家长粘贴作业 → 助手回复解析清单请确认 → 助手生成多风格图片发给家长 → 家长说"选第 2 张，把标题改成 XX" → 助手改后发终稿供下载打印。

### 异常与边界状态

| 状态 | 用户看到什么 |
|------|--------------|
| 作业内容为空/纯表情 | 提示"没有识别到作业内容，请粘贴老师的原文或上传截图" |
| OCR 置信度低 | 展示识别结果并标黄可疑处，请家长修正后继续 |
| 解析出 0 个有效项 | 展示原文，请家长手动拆条 |
| 生图失败/超时 | 自动重试 1 次；仍失败则提示并提供"先用标准清单模板出图"兜底 |
| 作业项超过 10 项 | 提示自动分页（A4 第 1/2 页）或建议合并同类项 |

## 技术选型

### 关键决策：文字层与美术层分离（本方案最重要的技术判断）

当前所有 AI 生图模型（含主流画图 AI）在**成段中文文字渲染上仍不可靠**——容易出现错字、乱码、笔画粘连。而本产品的生命线恰恰是"把每一项作业说明白"。因此采用双层合成架构：

```
AI 画图工具 ──► 生成「风格底图」（不含正文文字：背景、边框、路径、装饰、关卡框、图标）
排版渲染引擎 ──► 在底图的预留区域内「精确绘制」所有中文文字与勾选框
合成输出 ──► A4 300dpi PNG/PDF
```

- 底图生成：用画图 AI（通义万相 / 即梦 / GPT-Image 等均可）按每个骨架+皮肤组合生成一套**带留白区域的底图模板**，一次生成、长期复用，边际成本≈0；
- 文字绘制：程序化排版（HTML+CSS 渲染截图，或 Python Pillow/Skia 绘制），保证 100% 准确、可编辑、可换字体；
- 这也天然支撑了"④再编辑"能力——改文字不需要重新生图。

### 分阶段实施路线

**阶段 1 — 对话内工作流（MVP，0 开发成本，1 天内可用）**
- 载体：AI 助手对话（如本对话）；
- 解析：大模型完成作业文本结构化；
- 出图：AI 画图生成风格底图 + 排版合成 A4 成品图；
- 编辑/下载：对话内指令式修改，成品图直接发家长保存打印。
- 适合：先给自己孩子用，同时验证哪种风格孩子最买账。

**阶段 2 — 网页版生成器（验证后投入）**
- 前端：React/Next.js 单页应用（候选屏、编辑屏用 Canvas/DOM 实现所见即所得）；
- 后端：Node.js 或 Python FastAPI；解析用大模型 API；底图用画图 AI API + 本地模板库缓存；
- 渲染出图：Puppeteer/Playwright 将 HTML 版面截图为 300dpi PNG，或服务端 Skia 渲染；PDF 用同一版面导出；
- 存储：家长偏好与历史作业（SQLite/PostgreSQL 起步即可）；
- 部署：国内云服务器 + HTTPS；若走微信小程序触达其他家长，需另做小程序端与内容合规审核。
