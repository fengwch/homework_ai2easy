# Coze 工作流 - 图片生成流程

本目录提供「故事 → 插图提示 → 英文提示词优化 → 绘图 API」的完整工作流说明与结构化定义，便于在 [Coze（扣子）](https://www.coze.cn) 中复现或导入。

## 文件说明

| 文件 | 说明 |
|------|------|
| **图片生成工作流说明.md** | 流程说明、各节点输入/输出、**完整提示词**与配置参数，按节点 1～4 拆解。 |
| **coze-workflow-图片生成.json** | 工作流结构化定义（nodes + edges），含节点 id、提示词模板、config 默认值，便于按节点在 Coze 中创建或与导入格式对齐。 |

## 使用方式

- **在 Coze 中手动搭建**：打开 `图片生成工作流说明.md`，按「节点 1～4」在画布中创建「大模型」与「API」节点，将文档中的提示词与参数填入对应节点。
- **导入**：Coze 官方导入通常使用**从平台导出的 zip**。若平台支持从 JSON 导入工作流，可尝试使用 `coze-workflow-图片生成.json`；否则以 JSON 为参考，按节点复制提示词与参数到 Coze 中。

## 流程简述

1. **故事生成**：输入儿童档案 + 题目 → LLM 生成故事正文（含配图说明）。
2. **插图提示生成**：输入故事正文 → LLM 输出多句中文插图描述。
3. **英文提示词优化**：对每条中文描述 → LLM 输出一句英文绘图提示词（含风格、分镜、角色一致性）。
4. **绘图 API**：英文提示词 + 配置 → 调用 TTAPI Gemini 或 Midjourney，得到图片 URL。

配置项（风格、格数、比例、垫图等）见 `图片生成工作流说明.md` 与项目根目录 `configs/content_generation.yaml`。
