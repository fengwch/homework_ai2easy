# 产品定位与推广目的

## 1. 推广目的（为何写这些文档）

- **主要用途**：为**小红书、公众号、短视频口播文案**等「软推广」提供统一口径、可复制的素材与禁区说明。
- **次要用途**：内部对齐——产品、运营、客服对外说同一套「我们是谁、解决什么问题」。

## 2. 一句话定位（可按渠道微调）

**家长拍一拍作业，AI 把题目变成孩子喜欢的故事与练习，让辅导少一点吼叫、多一点兴趣。**

备选（更偏孩子视角）：

- 「把作业变成「娃爱听的故事」——AI 按孩子的兴趣来定制。」
- 「不是替代家长，而是把「讲题」和「编故事」交给 AI，家长只管陪伴与鼓励。」

## 3. 产品定位（产品思维）

| 维度 | 表述 |
|------|------|
| **我们是什么** | 面向家庭场景的 **AI 作业辅导与个性化学习辅助工具**（以儿童兴趣为导向的个性化内容生成 + 作业识别与练习）。 |
| **我们不是什么** | 不是完整 K12 网课、不是替代学校、不是线下家教；**不承诺**「提分保证」「替代教师」。 |
| **核心价值** | **个性化**（兴趣 + 档案）+ **趣味性**（故事、情景化）+ **减轻家长重复劳动**（识别、生成、引导）。 |
| **情感价值** | 缓解「辅导焦虑」与亲子冲突；让孩子觉得「学习可以和我喜欢的东西有关」。 |

## 4. 推广时建议强调的「差异化」

1. **兴趣绑定**：奥特曼、恐龙、科学、故事角色等，与知识结合，而不是千篇一律的题库。
2. **从作业出发**：先拍作业再生成，贴近真实作业场景，而不是空泛「刷题」。
3. **家长友好**：操作简单、步骤清晰；适合「没时间细讲每一题」的家庭。

## 5. 不适合的表述（避免误导）

- 避免「全科提分」「必考」「押题」等教育结果承诺。
- 避免「完全不用家长管」——产品定位是**辅助**，不是替代监护与学校教学。

## 6. 与 PRD 愿景对齐（便于核对）

- 愿景：「学习有趣，辅导无忧」——推广时**可**用口语化改写，**不要**夸大效果。
- 目标用户：以 **3–12 岁** 家庭为主，家长为**决策者**，儿童为**实际使用者**之一。
