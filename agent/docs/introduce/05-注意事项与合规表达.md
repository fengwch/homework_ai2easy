# 注意事项与合规表达

> 本文档面向**对外软文、小红书、短视频口播**，帮助避免夸大宣传与合规风险。具体以**法务/平台规则**及**当地教育类广告法规**为准。

## 1. 产品边界（必须说清）

| 项目 | 建议表述 |
|------|----------|
| 产品性质 | **学习辅助工具 / 家庭辅导辅助**，不是教育机构、不是在线学科培训资质替代物（以实际主体资质为准）。 |
| 与学校关系 | **不替代**课堂教学与教师评价，作业仍以学校要求为准。 |
| 家长责任 | **未成年人使用需家长监护**；家长应对内容做适当判断与限制使用时长。 |

## 2. 禁止或慎用的宣传用语

| 类型 | 示例（慎用/禁用） | 建议替换 |
|------|-------------------|----------|
| 成绩承诺 | 「必提分」「保过」「押题必中」 | 「帮助巩固」「个性化练习」 |
| 绝对化 | 「最好」「第一」「100% 准确」 | 「在清晰拍摄前提下力求识别准确」「以实际效果为准」 |
| 医疗/心理 | 「治疗厌学」「治愈焦虑」 | 「缓解辅导压力」「增加学习趣味」等温和表述 |
| 替代监护 | 「不用家长管」 | 「减轻重复讲解负担」「家长可陪伴与鼓励」 |

## 3. AI 生成内容相关

- 应提示：**AI 生成内容可能存在错误**，重要题目建议家长或教师核对。
- 图片、故事若涉及版权敏感角色名，**以产品实际策略与法务意见为准**；对外可泛化为「孩子喜欢的主题」。

## 4. 隐私与儿童个人信息

- 软文可一句带过：「请阅读隐私政策与儿童个人信息保护说明。」
- 避免在公开笔记中展示**真实孩子正脸、学校全名、试卷可追溯信息**。

## 5. 平台规则（小红书等）

- 避免违规导流：具体外链、联系方式以**平台当时规则**为准。
- 避免虚假宣传、对比贬损竞品。
- 若涉及「广告」或「合作」，按平台要求标注 **#广告** 或 **#合作**。

## 6. 免责声明方向（供运营/法务裁剪）

- 服务受网络、设备、模型能力影响，**不保证**不间断与无错误。
- 学习效果因个体差异而异，**不构成**教育结果承诺。

## 7. 危机话术（用户吐槽时）

- 先共情，再引导官方渠道反馈；**不**在公开评论区与用户对骂、不泄露内部信息。
