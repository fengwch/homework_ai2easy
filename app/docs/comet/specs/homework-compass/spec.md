# daily-homework-target — 每日作业目标生成器（前端）

## Intent

家长在首页（`pages/child/list.uvue`）的「作业工作台」里发起作业：上传作业、查看历史作业列表、或进入目标生成器。目标生成器把老师发的作业原文经过「解析 → 确认 → 生成目标图 → 选择与再编辑 → 下载」变成一张 A4 可打印目标图。后端引擎（`HomeworkCompass` Python 包 + FastAPI `api.py`）已实现，本次交付前端、首页重排及其 HTTP 接线。

## Goals

- 首页顶部「作业工作台」并列「上传作业」与「查看作业列表」，孩子卡片只负责展示与选中。
- 孩子卡片的选中、编辑、空态、加载、错误态清晰可用，触控区达标。
- 从「作业目标生成器」进入，五屏流程完整可用。
- 解析结果忠实原文：未确认项（pending）一律拦截，不出图。
- 出图为 A4 竖版 2480×3508 @300dpi PNG。

## Non-goals

- 作业列表页的「目标图」入口（删除）。
- 多版式骨架、AI 风格底图、LLM 解析、历史模板、对话式形态、PDF。
- 孩子卡片展示作业数量统计（无后端聚合接口）。

## Constraints

- 前端 uni-app x（`.uvue`，`<script setup lang="uts">`），H5 / 微信小程序为主；只在 HBuilderX 运行，不引入新的 npm 依赖。
- 页面不得直接调用 `agent/`；Compass 服务独立部署、独立域名，由前端直连，基址仅来自 `.env` 的 `VITE_COMPASS_API`（开发/生产各配一套），源码不回落到 localhost。
- `pending` 非空 → `/api/render` 返回 409，前端必须把原因展示给家长。
- 不在源码里写死密钥；不修改 `package.json` / 构建配置。
- 沿用现有视觉基线：主色 `#667eea`，页面底色 `#f5f5f5`，卡片白底 `16rpx` 圆角、`24rpx` 间距；正文 `≥ 28rpx`，辅助文字 `≥ 24rpx` 且对比度 ≥ 4.5:1。
- 不使用 emoji 作为可点击控件的图标，改用纯 view/文本绘制或项目内现有图标资源。

## Behavior

### 首页 · 作业工作台
- 位于首页问候语与孩子切换器下方，两张并列大卡（等宽，间距 `24rpx`）：
  - 「上传作业」— 副文案「拍照或从相册选择」，点击跳转 `/pages/assignment/scan`（沿用扫描页现有的拍照/相册选择）。
  - 「查看作业列表」— 副文案「历史作业与辅导」，点击跳转 `/pages/assignment/list`。
- 两张卡下方一条「作业目标生成器」次级入口，显示当前选中孩子姓名；无选中孩子时置灰不可点，点击提示「请先选择孩子」。
- 孩子卡片区域位于工作台下方，卡片上不再出现「上传作业」「上传识别」或「查看作业列表」按钮。

### 首页 · 孩子卡片
- 单卡内容：头像（`avatarUrl`，缺失时用姓名首字占位）、姓名（`32rpx` 加粗）、年级（`26rpx` 辅助色，缺失显示「未设置年级」）、「编辑」按钮（`≥ 88rpx × 88rpx` 触控区）。
- 整卡可点击：切换当前孩子并轻提示「已切换到 X」。
- 选中态三重编码：主色左边框/描边 + 浅主色底 + 右上角勾选徽章；未选中为白底细边框。
- 状态：
  - 加载中：两到三张骨架卡（灰块占位），不显示「还没有添加孩子」。
  - 加载失败：错误文案 + 「重试」按钮。
  - 无孩子：空态文案 + 引导到底部「添加小孩」。
- 无孩子或不加载时，工作台仍显示，但目标生成器入口置灰。

### 目标生成器 · 入口
点击「作业目标生成器」跳转 `/pages/compass/input?childId=<当前选中孩子 id>`。

### ① 输入屏
- 大粘贴框（主入口）；「上传图片」调 `/api/parse/image`（OCR），返回文本先展示给家长核对再进入解析结果。
- 唯一可见的额外输入：孩子姓名（默认取孩子卡片名字）。
- 空内容/纯符号 → 提示「没有识别到作业内容，请粘贴老师的原文或上传截图」。

### ② 确认屏
- 卡片列表：序号、科目、任务、数量、要求、重要徽章（`priority=high`）。
- 每项可编辑：科目、任务、数量、要求、优先级（调 `/api/correct`）。
- `pending`（歧义/未覆盖）红色高亮置顶，可「补进第 N 项」（correct）或「忽略」（dismiss）。
- `pending` 非空时「生成目标图」按钮不可用。

### ③ 候选屏
- 引擎只有一个骨架（`quest-map`），「候选」定义为 5 种配色（dinosaur / space / ocean / pixel / candy）并排预览，每个都是完整 A4 图。
- 「换一批」重新渲染。

### ④ 编辑屏
- 选中某张候选后进入；可修改标题/口号、按项改文字（correct）、更换配色重渲染。

### ⑤ 下载屏
- 展示最终 A4 图；提示保存方式（H5 右键/长按保存，小程序长按保存），打印贴士：「A4、实际大小、不缩放」。

### 异常
- 服务不可达：提示检查 Compass 服务是否启动。
- 409：展示逐条 pending 原因，引导回确认屏。

## Acceptance

- A1 首页工作台：「上传作业」「查看作业列表」两卡并列，分别进入扫描页与作业列表；孩子卡片上无上传/查看列表按钮。
- A2 目标生成器入口：有选中孩子时可进入输入屏且 `childId` 生效；无选中孩子时提示先选孩子；作业列表页无「目标图」。
- A3 粘贴原文 → 确认屏出现结构化清单；空内容有提示。
- A4 确认屏可编辑任一项字段，修改后清单更新；pending 置顶红色高亮。
- A5 存在 pending 时生成被拒（409），页面显示逐条原因。
- A6 候选屏同时展示 5 个配色 A4 预览，尺寸 2480×3508。
- A7 编辑屏可改标题口号、改某项文字，重新生成的图反映修改。
- A8 下载屏展示最终 A4 图，并有保存与打印提示。
- A9 孩子卡片显示头像/首字、姓名、年级；点击切换选中态；「编辑」进入编辑页。
- A10 选中态不只靠颜色（边框+底色+勾选徽章）；触控区 ≥ 44px；加载、失败、空态均可用。
