# 使用步骤与典型路径

> 说明：以下步骤与**核心功能规格**、**产品需求文档**中的主流程一致；若某版本功能有差异，以**当前上线版本**为准，并更新本文档。

## 1. 家长侧：首次使用（冷启动）

1. **下载 / 打开应用**（微信小程序、App 等以实际渠道为准）。
2. **注册 / 登录**（手机号、微信等，以实际为准）。
3. **创建儿童档案**（建议强调）：
   - 年龄、年级、昵称等基本信息；
   - **兴趣爱好**（多选、可自定义）——用于个性化故事与内容风格；
   - 可选：学习习惯、薄弱科目等，便于后续推荐。
4. 进入 **作业上传 / 扫描** 等入口，开始使用核心能力。

## 2. 核心路径：从作业到「故事 + 练习」

以下为**典型路径**，软文可压缩成 3～5 步讲清。

| 步骤 | 动作 | 用户感知 |
|------|------|----------|
| ① | 上传或拍摄作业图片 | 像拍作业发给老师一样简单 |
| ② | 系统识别题目（OCR + 解析） | 自动拆题、识别题型（可人工校对） |
| ③ | 触发「生成个性化内容」 | 等待生成（可展示进度） |
| ④ | 阅读**故事化学习材料** | 标题、摘要、故事正文、配图（若有） |
| ⑤ | **练习与答题** | 根据材料完成选择题等练习 |
| ⑥ | 可选：**打印预览**、朗读、分享等 | 巩固、打印纸质、家庭共读 |

### 2.1 多题作业场景

- 识别出**多道题**时，可按**单题**生成对应个性化内容（与 PRD 中单题能力一致）。
- 软文可讲：「孩子哪一题薄弱，就单独生成哪一题的故事」。

## 3. 作业详情页常见操作（与产品模块对齐）

- 查看作业状态：识别中、生成中、已完成等。
- **进入故事学习**：阅读 AI 生成的故事与插图。
- **去做题**：进入答题页巩固。
- **打印**：生成适合打印的预览（以实际页面为准）。

## 4. 软文可引用的「极简版」步骤（适合小红书正文）

**「拍作业 → 等一会儿 → 读故事 → 做题 → 打印」** —— 五步走，每步一句话即可。

## 5. 不适合写进软文的细节

- 内部接口名、技术栈、具体错误码。
- 未对全部用户开放的实验功能。
