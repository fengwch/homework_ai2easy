# 输出内容与价值主张

## 1. 用户能「看到 / 用到」的输出（与功能对齐）

以下内容类型适用于**软文「你能得到什么」**小节，请与**实际产品输出**一致，勿夸大。

| 输出类型 | 说明 | 推广时可怎么说 |
|----------|------|------------------|
| **故事化学习材料** | 标题、摘要、主题、故事正文等 | 「把题目变成孩子能听进去的故事」 |
| **插图 / 配图** | AI 生成或异步生成的配图（若有） | 「有图有画面，不是干巴巴文字」 |
| **练习题** | 与材料配套的选择题、应用题等 | 「学完就练，巩固知识点」 |
| **解题与引导** | 结构化讲解、思路引导（依模块而定） | 「讲清步骤，而不是只给答案」 |
| **打印版式** | 打印预览、导出为纸质 | 「打印出来，保护视力、方便批改」 |
| **语音朗读**（若已上线） | 朗读故事 | 「不费妈朗读，孩子边听边跟」 |

## 2. 价值主张（家长视角）

1. **省时间**：减少家长逐题编故事、找例题的时间。
2. **降冲突**：把「讲题」部分交给结构化内容与趣味包装，降低当场摩擦。
3. **更贴合孩子**：兴趣标签 + 档案，让内容不是「全网同一篇」。
4. **可追踪**：作业记录、完成状态等，便于家长了解进度（以实际功能为准）。

## 3. 价值主张（孩子视角）

- 故事、角色、画面感，比「再做一张卷子」更友好。
- 成就感：完成练习、看到故事与自己的兴趣相关。

## 4. 与竞品/通用工具的差异化（话术方向）

| 对比维度 | 我们可强调 |
|----------|------------|
| 通用 AI 聊天 | 我们**从作业出发**，有识别、题目结构与学习闭环 |
| 纯题库 App | 我们强调**个性化叙事与兴趣**，而非纯刷题 |
| 线下辅导 | 我们是**家庭场景工具**，不是替代老师面授 |

## 5. 软文「金句」备选（需合规审核后使用）

- 「不是多刷题，而是让这一题变得值得听。」
- 「兴趣不是锦上添花，是孩子愿意坐下来的理由。」
- 「家长的时间，留给鼓励和陪伴，而不是重复造故事。」

## 6. 不宜承诺的「输出」

- 不承诺「某次考试必考」「成绩一定提高」。
- 不承诺「插图与故事 100% 符合家长预期」——AI 生成存在**可编辑、可重试**空间（以产品为准）。
