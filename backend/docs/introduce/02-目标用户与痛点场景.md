# 目标用户与痛点场景

## 1. 核心用户画像（推广可讲故事，勿虚构具体姓名学校）

### 1.1 决策者：家长（主）

| 类型 | 特征 | 典型痛点 | 我们可承接的叙事 |
|------|------|----------|------------------|
| **职场忙碌型** | 工作时间长，晚上精力有限 | 没力气逐题讲解、容易急躁 | 「把讲解和故事交给工具，家长只做情绪与节奏」 |
| **方法焦虑型** | 重视教育但不懂怎么讲 | 孩子不爱听、一说就吵 | 「用孩子兴趣包装知识点，先愿意听再谈学会」 |
| **多孩家庭** | 时间被切碎 | 无法对每个孩子深度辅导 | 「单题/单份作业可独立生成，适配不同节奏」 |

### 1.2 使用者：儿童（辅）

- **年龄**：文档规划以 **3–12 岁** 为主（幼儿园至小学高年级，以产品实际上线范围为准）。
- **特点**：注意力短、对「故事、游戏、角色」敏感；对「干巴巴讲题」易抵触。
- **推广话术**：少用成人词，多用「像看故事一样」「像玩闯关一样」等感官描述（需与真实功能一致）。

### 1.3 次要关注者

- **祖辈**：若代为陪学，可强调「操作简单、有图有故事」。
- **教育类博主**：可强调「个性化 + 作业场景 + 家庭边界」而非「应试神器」。

## 2. 痛点场景（适合写成小红书「我遇到过」类笔记）

1. **作业磨蹭**：坐下半小时写两行——可讲「把题目变成故事线，先提起兴趣」。
2. **一讲就炸**：家长讲题孩子哭闹——可讲「换种方式呈现，减少正面冲突」（注意：不承诺「不再吵架」）。
3. **家长也不会**：高年级题家长拿不准——可讲「AI 做结构化讲解与练习引导」，**家长仍需核对与陪伴**。
4. **重复劳动**：每题都要找同类练习——可讲「从作业生成个性化拓展材料」。

## 3. 使用场景（时间 / 地点）

| 场景 | 描述 |
|------|------|
| **放学后** | 回家吃饭前后，完成校内作业后的「巩固与趣味化」 |
| **周末** | 集中处理一周错题、薄弱点 |
| **睡前** | 若产品支持朗读/故事，可强调「轻量、不费眼」的用法（以实际功能为准） |

## 4. 推广时「不要默认」的用户

- 完全无家长监护的幼儿（产品需家长账号与设备管理）。
- 期望「完全替代线下老师/一对一」的家庭——需管理预期。

## 5. 一句话总结（给投放素材用）

**「没时间、没方法、没耐心的家长」+「需要兴趣驱动的孩子」** —— 在「家庭作业辅导」场景下相遇。
