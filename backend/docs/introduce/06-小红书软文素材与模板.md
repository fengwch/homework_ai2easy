# 小红书软文素材与模板

> 用途：快速产出**种草笔记**、**图文大纲**、**口播脚本骨架**。请与 [05-注意事项与合规表达](./05-注意事项与合规表达.md) 一起使用。

## 1. 标题公式（20 字内可改）

| 类型 | 模板 |
|------|------|
| 痛点 | 「辅导作业到心梗？试试把题目变成『故事』」 |
| 好奇 | 「拍一张作业图，AI 能给孩子讲什么？」 |
| 场景 | 「双职工家庭晚上 8 点，我们这样搞定作业」 |
| 利益 | 「少吼一次是一次：给家长的作业辅导偷懒法」 |
| 对比 | 「不是刷题 App，是会把作业变『好玩』的工具」 |

## 2. 正文结构（五段式）

1. **钩子**（3 行内）：场景 + 情绪（如「以前一讲题就吵」）。
2. **转折**：遇到「把作业变成故事」的工具（不夸大品牌，可用「智趣作业辅导」等正式名）。
3. **步骤**：拍作业 → 识别 → 生成 → 读故事 → 做题（见 [03-使用步骤与典型路径](./03-使用步骤与典型路径.md)）。
4. **真实感受**：家长/孩子各一句（可匿名）。
5. **收尾 + 合规**：辅助工具、需家长陪伴、效果因人而异。

## 3. 短文案（适合配图封面）

- 「作业先拍一拍，故事讲给娃听。」
- 「兴趣对口了，娃才坐得住。」
- 「不是替代你，是帮你少编一百个故事。」

## 4. 话题标签（按需组合，以平台热门度为准）

**教育类**：`#亲子教育` `#家庭教育` `#小学作业` `#辅导作业` `#学习好物`

**家长类**：`#宝妈日常` `#宝爸带娃` `#双职工家庭` `#育儿分享`

**效率类**：`#学习工具` `#效率神器` `#AI工具`（若平台允许）

**产品向（谨慎）**：使用官方品牌话题（若有）、活动话题；避免堆砌无关标签。

## 5. 配图 / 封面建议

| 类型 | 建议 |
|------|------|
| 封面 | 大字标题 + 温馨场景（家庭书桌、无隐私信息） |
| 内图 | 产品界面截图需**脱敏**（无真实姓名、学校、完整题目） |
| 对比 | 「使用前烦躁 vs 使用后平静」可用手绘/表情包，避免真实儿童丑化 |

## 6. 视频口播 30 秒脚本骨架

1. 前 5 秒：「有没有同款家长，一辅导作业就上头？」
2. 5–15 秒：「我现在用××，先拍作业，它生成故事和练习。」
3. 15–25 秒：「孩子至少愿意先看故事，再做题。」
4. 最后 5 秒：「工具只是辅助，陪伴还是咱们自己来。感兴趣的可以搜××。」

## 7. 系列选题建议（可连载）

| 期数 | 选题方向 |
|------|----------|
| 1 | 为什么孩子不听你讲题？可能是「形式」不对 |
| 2 | 单题薄弱怎么补？单题生成故事怎么用 |
| 3 | 打印出来：纸质 vs 屏幕，我家怎么选 |
| 4 | AI 也会错：家长该怎么核对 |
