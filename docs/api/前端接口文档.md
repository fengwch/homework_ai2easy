## 通用说明

### 基础信息

- **Base URL**: 根据环境变量配置（`VITE_API_BASE_URL`）
- **API版本**: `/api/v1`
- **请求格式**: JSON
- **响应格式**: JSON

### 请求头

所有需要认证的接口都需要在请求头中携带：

```
Authorization: Bearer {token}
X-Platform: {平台标识}
X-Device-Id: {设备ID}
Content-Type: application/json
```

### 响应格式

所有接口统一返回格式：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

**响应码说明**：
- `code: 0` - 成功
- `code: 401` - 未授权，需要重新登录
- `code: 400` - 请求参数错误
- `code: 404` - 资源不存在
- `code: 500` - 服务器错误

### 3. 微信一键登录（含小程序静默登录）

**接口路径**: `POST /api/v1/auth/wechat-login`  
**后端需实现** · 前端已对接 · 开发阶段：第二阶段（用户管理）

**接口说明**: 使用微信授权登录。**小程序端**会在 App 启动时无 token 的情况下静默调用本接口（仅传 `code`），实现「无需登录页、默认已登录」。昵称、头像需用户主动点击「授权获取微信昵称头像」按钮后通过 `wx.getUserProfile` 获取，再调用 `PUT /api/v1/user/profile` 同步，在 `pages/child/list`、`pages/profile/index` 展示。

**请求参数**:
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | 是 | 微信登录凭证。小程序端由 `wx.login` / `uni.login` 获得，5 分钟有效 |
| nickName | string | 否 | 用户昵称（由 `wx.getUserProfile` / `uni.getUserProfile` 获取） |
| avatarUrl | string | 否 | 头像 URL（由 `wx.getUserProfile` / `uni.getUserProfile` 获取） |

```json
{
  "code": "081xYyll2ABCde0Xyzll2defGH34",
  "nickName": "用户昵称（可选）",
  "avatarUrl": "https://thirdwx.qlogo.cn/...（可选）"
}
```

**说明**：`wx.getUserProfile` 需用户主动点击按钮触发授权弹窗（基础库 2.10.4+），静默登录时不调用。昵称头像在个人中心点击「授权获取微信昵称头像」后获取，并调用 `PUT /api/v1/user/profile` 保存。

**响应数据**:
```json
{
  "code": 0,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userInfo": {
      "id": 1,
      "phone": "13800138000",
      "nickname": "微信昵称",
      "avatarUrl": "https://example.com/avatar.jpg",
      "wechatOpenId": "openid123"
    }
  }
}
```

**小程序静默登录 — 后端需实现要点**（方便后端对接）：

1. **用 code 换 openid**  
   后端收到 `code` 后，调用微信服务端接口 [auth.code2Session](https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/user-login/code2Session.html)（小程序 AppID + AppSecret + code），换取 `openid`、`session_key`（及可选 `unionid`）。

2. **按 openid 查用户 / 自动注册**  
   - 若已有该 `openid` 对应用户：生成或刷新该用户的登录态（如 JWT），并返回 `token` 与 `userInfo`。  
   - 若不存在：**自动创建账号**（建议至少落库 `openid`，`nickname`/`avatarUrl`/`phone` 可先为空或默认值，后续用户通过「绑定手机号」等再补全）。

3. **响应格式**  
   与上文「响应数据」一致：`data.token`、`data.userInfo`（`userInfo` 需含 `id`，建议含 `nickname`、`avatarUrl`、`wechatOpenId` 等，字段可下划线或驼峰，前端已做兼容）。

4. **错误与降级**  
   - `code` 无效、过期或微信接口失败：建议返回 `code: 400` 或 `401`，并 `message` 说明（如「登录凭证无效」）。  
   - 前端收到非成功响应时，不会弹登录页打断用户，仅静默失败；需要登录的页面在检测到无 token 后会再跳转登录页。

5. **安全与配置**  
   - AppSecret 仅存后端，不要下发给前端。  
   - 小程序需在微信公众平台配置合法域名（request 域名包含后端接口域名）。

**接口说明**: 更新用户个人信息。**编辑个人信息**（`pages/profile/edit`）保存时会调用本接口，后端需实现以支持昵称、邮箱、头像 URL 的保存。

```json
  "email": "newemail@example.com",
  "gender": 1,
  "birthday": "1990-01-01"
```

```json
{
  "code": 0,
  "message": "更新成功",
  "data": {
    "id": 1,
    "phone": "13800138000",
    "nickname": "新昵称",
    "avatar_url": "https://example.com/new-avatar.jpg",
    "avatarUrl": "https://example.com/new-avatar.jpg",
```

- 每个 `questions` 数组元素需包含 `generatedContent`（或 snake_case `generated_content`），用于前端「生成内容」「开始学习」按钮状态以及**单题插图生成状态**：
  - `status`: `"none"` / `"pending"` / `"processing"` / `"completed"` / `"failed"`
  - `storyId` / `story_id`: 生成完成时返回，用于跳转 `GET /api/v1/contents/{story_id}` 学习页
  - 可选：`imageStatus` / `image_status`、`imageProgress` / `image_progress`、`imageUrls` / `image_urls`：
    - `imageStatus`: `"none"` / `"pending"` / `"processing"` / `"completed"` / `"failed"`
    - `imageProgress`: 图片生成进度百分比（0–100，可选）
    - `imageUrls`: 图片生成完成后返回的插图 URL 数组（完成前可为 `null` 或空数组）
- 未生成过时可为 `null` 或不返回该字段；生成中/完成/失败时需返回对应 `status` 与 `storyId`（完成时必填），如有图片生成则同步返回 `imageStatus`，可选返回 `imageProgress` 与 `imageUrls`。
- 前端据此判断：有 `storyId` 且 `status === "completed"` 显示「开始学习」，`status === "processing"` 显示「生成中...」；同时根据 `imageStatus` / `imageProgress` 在题目旁单独展示「插图生成中」「图片生成失败」或插图预览。

**作业状态说明（前端详情页展示「待处理」时，后端需配合完成）**  
- 作业状态枚举：`pending`（待处理）→ `processing`（处理中）→ `completed`（已完成）或 `failed`（失败）。
- 上传接口仅创建作业并落库图片，初始状态为 **pending**。要让详情页从「待处理」变为「处理中」再变为「已完成」并展示识别结果，后端需完成以下**任选一种**方案（或两种都支持）：

**方案一：上传后自动触发识别（推荐）**  
1. 在 `POST /api/v1/assignments/upload` 保存文件并创建作业记录后，**异步触发 OCR 任务**（如写入队列或后台任务）。  
2. 任务执行过程中将作业状态更新为 `processing`，识别完成后更新为 `completed` 并写入 `questions`；失败则更新为 `failed`。  
3. `GET /api/v1/assignments/{id}` 必须返回**最新**的 `status` 及识别完成时的 `questions` 数组，前端据此展示「处理中」或「识别结果」。

**方案二：由前端/用户主动触发识别**  
1. 实现 **`POST /api/v1/assignments/{id}/scan`**（按作业 ID 触发识别）：  
   - 请求体可选：`{ "subject": "数学" }`。  
   - 后端根据作业 ID 取已上传的图片，提交 OCR，并将作业状态置为 `processing`；识别完成后更新为 `completed` 并写入 `questions`。  
   - 响应示例：`{ "code": 0, "data": { "assignmentId": 1, "status": "processing", "progress": 0 } }`。  
2. 前端在详情页对「待处理」作业展示「开始识别」按钮，调用上述接口后轮询 `GET /api/v1/assignments/{id}/scan-status`，完成后刷新 `GET /api/v1/assignments/{id}`。  
3. 若采用现有 **`POST /api/v1/assignments/scan`**（传 `image_data`/URL、`child_id`、`subject`），后端需在识别完成后**把结果写回该作业**（按 `assignmentId` 或约定关联），并更新作业状态与 `questions`，保证 `GET /api/v1/assignments/{id}` 返回最新状态和题目。

**后端必须保证**  
- `GET /api/v1/assignments/{id}` 的 `data.status` 与 `data.questions` 与真实识别进度一致；  
- 识别完成后 `status` 为 `completed` 时，`questions` 为非空数组；  
- 若支持轮询进度，`GET /api/v1/assignments/{id}/scan-status` 的 `data.status` 为 `complete` 时，`data.questions` 可返回题目列表（或前端仅依赖详情接口刷新即可）。

### 15.0 导出学习材料 PDF（小程序端）

**接口路径**: `POST /api/v1/contents/{story_id}/export-pdf`  
**后端已实现** · 前端可对接 · 开发阶段：第五阶段（AI内容生成展示）

**接口说明**: 小程序平台无法直接调起系统打印（会显示「当前平台不支持打印」），可通过本接口由服务端生成 PDF 并返回临时下载链接。前端使用 `uni.downloadFile({ url })` 下载后，用 `uni.openDocument({ filePath, fileType: 'pdf' })` 打开，用户可预览、转发或保存。需登录后调用。

**路径参数**:
- `story_id`: 故事ID（与「获取学习材料」中的 `storyId` 一致）

**请求体**: 无（或 `{}`），鉴权依赖 Header 中的 `Authorization`。

**响应数据**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "url": "https://your-domain.com/api/v1/contents/pdf-download?token=xxx"
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| url | string | 临时 PDF 下载地址；带 token 的 GET 链接，有效期约 10 分钟，**无需鉴权**（便于小程序 `uni.downloadFile` 直接下载）。下载接口：`GET /api/v1/contents/pdf-download?token=xxx` |

**小程序要求**：该 URL 所在域名须在公众平台配置为 **downloadFile 合法域名**，且服务端 **TLS 版本必须 ≥ 1.2**，否则会报错 `downloadFile:fail 小程序要求的 TLS 版本必须大于等于 1.2`。请确保 Nginx/负载均衡/后端启用 TLS 1.2 及以上并禁用 TLS 1.0、1.1。

**后端实现说明**（当前已实现）:
1. 根据 `story_id` 拉取学习材料（同 GET 学习材料逻辑），包含 title、summary、story、questions（配图可选纳入 PDF）。
2. 服务端使用 Go 生成 PDF，写入临时文件，在 Redis 中存储 token → 文件路径，TTL 10 分钟。
3. 返回 `data.url` 为当前请求 Host 的 `GET /api/v1/contents/pdf-download?token=xxx`，前端用该 URL 调用 `uni.downloadFile` 即可；下载接口不校验 Authorization，一次有效，用后即删。

**中文字体**（可选）: 若需 PDF 内中文显示正常，可在服务端配置环境变量 `PDF_FONT_PATH` 指向 TTF 文件路径，或放置 `fonts/NotoSansSC-Regular.ttf` 等；未配置时使用默认字体（中文可能显示异常）。

**使用流程**:
1. 用户在学习材料页或作业详情点击「打印/导出 PDF」（小程序端因不支持打印可改为「导出 PDF」）。
2. 前端请求本接口，传入当前学习材料的 `storyId`。
3. 用返回的 `data.url` 调用 `uni.downloadFile({ url: data.url })`，成功后 `uni.openDocument({ filePath: res.tempFilePath, fileType: 'pdf' })` 打开，用户可转发或保存。

#### 17.1 提交合成任务

**接口路径**: `POST /api/v1/voice/synthesize`  
**后端需实现** · 前端已对接 · 开发阶段：第五阶段（AI 内容朗读）

**接口说明**: 提交语音合成任务，立即返回任务 ID。需登录。主后端可转发至 AI-Agent 或自建 TTS，**前端无需按字数截断**。AI-Agent 未配置时返回 503。

**请求参数**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| text | string | 是 | 要朗读的文本（如故事正文、解题引导），支持任意长度 |
| voice | string | 否 | 发音人，默认 `xiaoyun`。儿童友好推荐：`xiaoyun`、`ruoxi`、`siqi` |
| format | string | 否 | 音频格式，默认 `mp3`，可选 `wav` |
| speech_rate | number | 否 | 语速 -500～500，0 为默认，正数加快、负数变慢 |

```json
{
  "text": "小明在做数学题时遇到了难题，偶数是能被2整除的数。",
  "voice": "xiaoyun",
  "format": "mp3",
  "speech_rate": 0
}
```

**响应数据**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_id": "voice-xxx-123"
  }
}
```

**错误响应**:

| code | HTTP 状态码 | 说明 |
|------|-------------|------|
| 400 | 400 | 参数错误（text 为空） |
| 503 | 503 | 语音合成服务未配置（AI-Agent 未配置阿里云 TTS） |
| 500 | 500 | 服务器内部错误 |

#### 17.2 查询合成状态（轮询）

**接口路径**: `GET /api/v1/voice/synthesize/status`  
**后端需实现** · 前端已对接

**接口说明**: 根据任务 ID 查询合成状态。前端轮询此接口直至 `status` 为 `completed` 或 `failed`。

**请求参数**（Query）:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| task_id | string | 是 | 提交合成任务时返回的 task_id |

**响应数据**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "status": "completed",
    "audio_data": "<base64 编码的音频数据>",
    "format": "mp3"
  }
}
```

**status 取值**:

| status | 说明 |
|--------|------|
| pending | 排队中 |
| processing | 合成中 |
| completed | 已完成，此时返回 `audio_data`、`format` |
| failed | 失败，此时返回 `message`（可选） |

**completed 时 data 示例**:
```json
{
  "status": "completed",
  "audio_data": "<base64 编码的音频数据>",
  "format": "mp3"
}
```

**failed 时 data 示例**:
```json
{
  "status": "failed",
  "message": "合成超时"
}
```

**错误响应**（如 task_id 不存在）:

| code | HTTP 状态码 | 说明 |
|------|-------------|------|
| 404 | 404 | 任务不存在 |
| 500 | 500 | 服务器内部错误 |

**前端使用说明**：提交任务后轮询状态接口，当 `status === 'completed'` 时用 `audio_data` 生成 `data:audio/mp3;base64,...` 供 `<audio>` 或 InnerAudioContext 播放。详见 `docs/api/Agent-API.md` 语音合成章节。

## 注意事项

1. **认证要求**: 除登录、注册、发送验证码等公开接口外，其他接口都需要在请求头中携带有效的 `Authorization` token。

2. **文件上传**: 上传图片时使用 `multipart/form-data` 格式，文件大小限制为 10MB，支持的格式：jpg, jpeg, png。

3. **分页**: 列表类接口如果数据量大，建议实现分页功能。作业列表接口已包含分页参数，其他列表接口可根据实际需求添加。

4. **时间格式**: 所有时间字段使用 ISO 8601 格式：`YYYY-MM-DDTHH:mm:ssZ`

5. **图片URL**: 返回的图片URL可能是临时URL，建议前端进行缓存处理。

6. **识别进度**: OCR识别是异步任务，建议使用轮询或WebSocket方式获取识别进度。

7. **错误处理**: 所有接口调用失败时，前端应统一处理错误提示，并根据错误码进行相应的业务处理。

8. **作业上传流程**: 
   - 单图上传：使用 `/api/v1/assignments/upload` 上传图片，返回作业ID
   - 识别处理：上传后可直接跳转到识别页面，或调用 `/api/v1/assignments/scan` 进行识别
   - 多图处理：如需上传多张图片，建议先上传第一张创建作业，然后通过更新接口添加其他图片URL

9. **内容生成与学习流程**:
   - 作业级：调用 `/api/v1/assignments/{assignmentId}/generate` 开始生成，轮询 `generate-status` 获取 `storyId`
   - 单题级（2.4.3）：调用 `POST /api/v1/assignments/{id}/questions/{questionId}/generate` 为单题生成，轮询 `questions/{questionId}/generate-status` 获取 `storyId`
   - 生成完成后，调用 `GET /api/v1/contents/{storyId}` 获取学习材料，用于「开始学习」页面展示
   - 在线答题时，调用 `POST /api/v1/questions/{questionId}/answer` 提交每道题答案（后端需持久化），用于正误判断与反馈
   - 批改页调用 `GET /api/v1/assignments/{id}/answers` 获取小孩作答记录与分数（无标准答案不给出分数）

10. **儿童档案兴趣标签**:
    - 预设兴趣标签和自定义兴趣标签合并后总数不超过5个
    - 自定义兴趣标签最多3个，每个不超过5个字
    - 创建和更新时，`interests` 字段应包含所有兴趣（预设+自定义），`customInterests` 字段仅包含自定义兴趣

11. **小程序静默微信登录**:
    - 小程序端在 App 启动时若无 token，会调用 `uni.login` 获取 `code`，请求 `POST /api/v1/auth/wechat-login` 仅传 `code` 完成登录
    - 昵称、头像由用户在个人中心点击「授权获取微信昵称头像」按钮后通过 `wx.getUserProfile` 获取，再调用 `PUT /api/v1/user/profile` 同步
    - 后端需实现：用 `code` 调微信 code2Session 换 openid → 按 openid 查/建用户 → 返回 `token` 与 `userInfo`（详见本文档「3. 微信一键登录」中小程序静默登录后端要点）
    - 未实现或返回失败时，前端静默失败，需要登录的页面会再跳转登录页

12. **语音合成（异步）**:
    - 主后端 `POST /api/v1/voice/synthesize` 接收 text/voice/format/speech_rate，创建任务并立即返回 `task_id`
    - 主后端需实现 `GET /api/v1/voice/synthesize/status?task_id=xxx`，返回 `status`（pending/processing/completed/failed），completed 时返回 `audio_data`（base64）、`format`
    - 后端可排队、限流或转发至 AI-Agent 的 `/voice/synthesize`，需配置 Agent 服务地址及阿里云 TTS；Agent 支持任意长度文案
    - Agent 未配置时 POST 返回 503，前端应提示「语音合成服务暂不可用」
    - 前端轮询状态接口直至 completed 或 failed，再用 `audio_data` 生成 `data:audio/mp3;base64,...` 播放
